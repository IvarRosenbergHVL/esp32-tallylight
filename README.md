# esp32-tallylight

ESP32-based tally light for vMix. Built with PlatformIO.

## Overview
- Controls an LED tally light connected to an ESP32.
- Uses vMix API client to receive tally states.

## Build
Requirements: PlatformIO and an ESP32 board.

```bash
# build and upload with PlatformIO
platformio run
platformio run --target upload
```
