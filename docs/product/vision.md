# Product Vision

The ESP32 Tally Light is a compact, wireless device designed to provide real-time visual feedback (tally) for video production environments.

## Goals

- Provide a low-cost, portable tally solution
- Support multiple production systems (vMix, OBS, ATEM)
- Enable simple configuration without requiring a computer
- Deliver stable and predictable behavior in live environments

## Non-Goals

- Full control surface functionality
- Complex UI or display-based interaction
- Cloud dependency

## Target Users

- Small production teams
- Streaming setups
- Educational institutions
- Event production crews

## Key Value Proposition

A simple, reliable tally device that "just works" across different production systems.
